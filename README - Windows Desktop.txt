ENIGMA - ORIGINAL DESKTOP APPLICATION

How to launch (Windows):
1. Extract the ZIP (right-click > Extract All).
2. Double-click "Run Enigma.bat" inside the Enigma folder.
3. The original Enigma desktop window opens.

Requirement: Java 17 or newer must be installed.
Download it from https://adoptium.net/temurin/releases/?version=17
After installation, restart the launcher.

This package preserves the entire original project, source files, interface, and original JAR unchanged. Only this README and the launcher have been added.

Alternative: open a terminal in Enigma and run:
java -jar out\artifacts\Enigma_jar\Enigma.jar

Note: This is a Windows .bat launcher, not a standalone .exe. Java is required.
